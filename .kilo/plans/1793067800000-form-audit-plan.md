# Form Audit & Standardization Plan

## Overview
Audit all private page forms for consistency in: placeholder text, title handling, button variants, input sizing, error handling, and char counters. Ensure forms follow the established patterns across the codebase.

## Current Form Pattern Analysis

### 1. NoteForm (components/notes/NoteForm.tsx)
- **Pattern**: Textarea with char counter (280 max), placeholder "Apa yang kamu rasakan hari ini?"
- **Inputs**: `h-10 w-full rounded-xl border border-input bg-card px-4 py-3 pr-16 text-sm`
- **Button**: `type="submit" disabled={!content.trim() || createNote.isPending} className="w-full gap-2"` (default variant)
- **Issue**: No title field, just content. Placeholder could be more descriptive.

### 2. AddMilestoneForm (components/timeline/AddMilestoneForm.tsx)
- **Pattern**: Title + description + date + icon + color + location + photos
- **Title Input**: `placeholder="Contoh: First Date"`, `h-10 w-full rounded-xl border border-input bg-muted px-4 py-2 text-sm`
- **Description**: `placeholder="Ceritakan momen ini..."`, same input class
- **Date**: `type="date"` input
- **Icon/Color**: Emoji/color selection grid
- **Photos**: Upload with crop preview
- **Buttons**: "Batal" (outline, size="sm") + "Simpan/Tambah Milestone" (default, flex-1)
- **Issue**: Inconsistent input bg-color (bg-card vs bg-muted), no char counter, title placeholder format varies

### 3. WishForm (components/wishlist/WishForm.tsx)
- **Pattern**: Title + description + category + link + photo
- **Title Input**: `placeholder="Apa yang kalian inginkan?"`, required, has error state
- **Description**: `placeholder="Ceritakan impian kalian..."`, 2 rows
- **Link**: `placeholder="https://..."`, type="url", error state for invalid URL
- **Category**: Chips with selection
- **Photos**: Upload preview with cropper
- **Buttons**: "Batal" (outline, flex-1) + "Tambah Wish/Simpan" (default, flex-1)
- **Issue**: Link validation only on submit, no char counter on title/description

### 4. NewLetterForm (components/letters/NewLetterForm.tsx)
- **Pattern**: Title + mood + content (LetterEditor) + time capsule + submit
- **Title**: `placeholder="Contoh: Untuk kamu yang selalu ada"`, maxLength=200, error state
- **Content**: LetterEditor with toolbar (now single-row on mobile), placeholder "Mulai dengan..." 
- **Time Capsule**: Date + time inputs
- **Buttons**: "Batal" (now default variant) + "Kirim Surat" (default, flex-1)
- **Issue**: Content via dynamic LetterEditor component, time format now colon-separated

### 5. NotesManager (components/dashboard/NotesManager.tsx)
- **Pattern**: Textarea with char counter (280 max), placeholder "Apa yang kamu rasakan hari ini?"
- **Input**: `h-10 w-full rounded-xl border border-input bg-card px-4 py-3 pr-16 text-sm`
- **Button**: `type="submit" disabled={!content.trim() || createNote.isPending} className="w-full gap-2"` (default variant)
- **Issue**: Same as NoteForm - no title field

| AddMilestoneForm | "Contoh: First Date" | ∞ (no max) | ✗ |

### Mobile Responsiveness

- Most inputs are `w-full` but some container layouts need review

## Recommended Standardization

### 1. Unified Input Class
Use consistently: `h-10 w-full rounded-xl border border-input bg-card px-4 py-3 text-sm outline-none focus-visible:ring-2 focus-visible:ring-ring`
- Or: `h-10 w-full rounded-xl border border-input bg-muted px-4 py-2 text-sm outline-none focus-visible:ring-2 focus-visible:ring-ring`
- **Decision**: Use `bg-card` consistently for forms in dashboard/private pages, `bg-muted` for overlay modals

### 2. Title Field Addition
Add optional title field to Note-forming components where content-only exists:
- NoteForm/NotesManager: Consider adding title input above textarea
- Or keep as content-only but standardize placeholder format

### 3. Char Counter Standardization
Add char counter to all free-form text inputs:
- AddMilestoneForm description
- WishForm description
- Consistent format: `{current}/{max}`

### 4. Button Variant Consistency
- Primary actions (submit): Use `variant="default"` 
- Secondary actions (cancel/reset): Use `variant="outline"`
- This matches the fix already applied to NewLetterForm

### 5. Placeholder Text Guidelines
- Title: `Contoh: [example]` format
- Description: Descriptive prompt about content
- Link: `https://...` format with type="url"
- Content: "Mulai dengan..." or similar

### 6. Error Handling Pattern
- Show error state immediately on input blur or real-time
- Use `aria-invalid` and `aria-describedby` for accessibility
- Display error message with `role="alert"` and `text-destructive` class

### 7. Form Layout Consistency
- Use `space-y-3` or `space-y-4` consistently within forms
- Group related fields together
- Keep label + input on same line when space allows
